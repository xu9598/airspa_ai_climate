# 艾尔斯派 AI 五恒 Home Assistant 集成

版本：`1.3.8`（正式版）

正式版已移除旧版本标识、硬编码 AppID 和真实设备标识。AppID 与设备 DID 只在安装时由用户填写，并保存在你的 Home Assistant 配置中。

新增“室内温度评价”和“室内湿度评价”两个只读文本传感器，显示规则与小程序一致：温度低于 18℃ 为“寒冷”、18–26℃ 为“温和”、高于 26℃ 为“炎热”；湿度低于 40% 为“干燥”、40–60% 为“舒适”、高于 60% 为“潮湿”。

该设备协议只使用 AppID、DID 和设备 WebSocket 地址。配置表单、登录报文、客户端参数和文档中的 UID/Token 已全部移除；升级时会自动清理旧配置里残留的值。

这是根据小程序真实 WebSocket 抓包制作的自定义集成。监测部分已在 HAOS 中验证，其余控制指令来自后续抓包。

## 实体

- 独立“开关”开关实体（和负离子、睡眠一样显示开/关状态）
- 独立模式开关：智能、新风、内循环、混风（和负离子同样式；打开任一模式会先开机再切到该模式，关闭当前模式会关机）
- 独立“运行模式”下拉：显示当前模式，选项为智能、新风、内循环、混风
- 独立“风速”下拉：自动、1档、2档、3档、4档、5档（沿用 v1.0.0 的六档合并方式）
- 睡眠模式
- 负离子
- 摆风
- 云端连接（诊断用二进制传感器，附带连接阶段、原始帧计数和解析错误等属性）
- 室内温度及温度评价、室内湿度及湿度评价、室内 PM2.5、室内 CO₂
- 室外温度、室外湿度、室外 PM2.5、室外空气质量
- 滤网寿命

不提供温度设定，因为所提供的小程序页面和抓包中没有该功能。

## 巴法云接入

本版已删除 `climate` 空调实体。巴法云不识别 `select`，可以同步的是开关实体：`开关`、`智能`、`新风`、`内循环`、`混风`、`睡眠模式`、`负离子`、`摆风`。`运行模式`和`风速`两个下拉不会出现在巴法云设备里。

1. 在 Bemfa 集成中打开“同步实体”。
2. 选择需要同步的开关实体。
3. 四个模式开关已经包含开关机：打开任一模式会开机并切换模式，关闭当前模式会关机。

## 安装

### 通过 HACS 安装

1. 打开 HACS → 集成。
2. 点击右上角菜单，选择“自定义存储库”。
3. 添加仓库地址 `https://github.com/xu9598/airspa_ai_climate`，类型选择“集成”。
4. 搜索“艾尔斯派 AI 五恒”并安装。
5. 重启 Home Assistant，然后在“设置 → 设备与服务 → 添加集成”中配置。

### 手动安装

1. 解压 ZIP。
2. 将其中的 `custom_components/airspa_ai_climate` 整个目录复制到 Home Assistant 配置目录的 `custom_components` 下。HAOS 可使用 Samba、Studio Code Server 或 File Editor 等加载项。
3. 最终路径必须是：

   ```text
   /config/custom_components/airspa_ai_climate/manifest.json
   ```

4. 重启 Home Assistant。
5. 打开“设置 → 设备与服务 → 添加集成”，搜索“艾尔斯派 AI 五恒”。

## 从旧版升级

1. 用新版 `airspa_ai_climate` 目录覆盖旧目录，不要删除集成或设备。
2. 重启 Home Assistant。
3. 已经验证可用的 `wss://aisp.airspa.cn:81/完整DID` 自定义地址会原样保留，不会被迁移改写。
4. 旧沙箱地址或 `/ws/app/v1` 通用地址会迁移为设备路径模板。
5. 旧版残留的 UID/Token 配置会在升级时自动删除；DID 不变。
6. 本版删除了 `climate` 空调实体；四个模式开关恢复为带开关机的行为：打开任一模式会先开机再切模式，关闭当前模式会关机。旧版留下的“空调控制”实体会变成不可用，可在实体列表里手动删除。`运行模式`下拉、`风速`下拉、睡眠、负离子、摆风和其他实体保留。

## 配置项

| 字段 | 填写方式 |
| --- | --- |
| AppID | 填写小程序登录报文中的 AppID；正式版不预置任何 AppID |
| 设备 DID | 单独填写状态回复 `data.did` 的完整值，保留大小写 |
| WebSocket 服务地址 | 填写服务器地址，默认 `wss://aisp.airspa.cn:81`；系统会自动在末尾拼接完整 DID。留空则使用官方地址 |

更新配置页会显示设备 DID 独立字段，默认填入当前值且不允许修改；只允许修改服务器地址，避免改名 DID 后产生重复实体。旧版保存的完整地址或 `{device_id}` 模板会自动迁移为“服务器地址 + DID”。

必需请求头已内置：`Origin: https://aisp.airspa.cn:81`，并使用抓包中的完整微信/小程序 User-Agent。

源代码没有写入 AppID 或 DID；该协议不使用 UID/Token，相关配置字段已全部移除。

## 隐私与标识

- 源码、翻译、文档和安装包中不包含真实 AppID、DID、MAC、passcode、openid 或会话密钥。
- AppID 与 DID 仅在用户填写后保存在 Home Assistant 的配置条目中。
- 自动化测试使用合成 DID（`productkey_001122334455`），与实际设备无关。
- 服务域名、Origin 和通用小程序 User-Agent 是协议连接参数，不属于个人标识。

## 睡眠、负离子、摆风协议

| 功能 | 开启指令 | 关闭指令 | 状态字节 |
| --- | --- | --- | --- |
| 睡眠模式 | `0000002001` | `0000002000` | 11 |
| 负离子 | `0000004001` | `0000004000` | 12 |
| 摆风 | `0000080001` | `0000080000` | 17 |

以上三个功能的最终映射由两次实测回显反推确认：睡眠对应 `0x20`/字节 11，负离子对应 `0x40`/字节 12，摆风对应 `0x0800`/字节 17。

所有控制指令都带有配置中的完整 `data.did`。集成不会乐观猜测状态；发送后等待设备下一条 `s2c_raw` 状态帧更新实体。

偏移均从 0 开始：

| 偏移 | 含义 |
| --- | --- |
| 8 | 电源：`0=关机`、`1=开机` |
| 9 | 模式：`0=智能`、`1=新风`、`2=内循环`、`3=混风` |
| 10 | 风速：`0=自动`、`1–5=档位` |
| 11 | 睡眠模式开关 |
| 12 | 负离子开关 |
| 15 | 预留，未使用 |
| 17 | 摆风开关 |
| 18 | 室内温度，原始值减 20（`0x2B=43 → 23°C`） |
| 19 | 室内湿度，单字节百分比 |
| 20 | 室外温度，单字节有符号整数 |
| 21 | 室外湿度，单字节百分比 |
| 22–23 | 室内 CO₂，大端无符号整数 |
| 24–25 | 室内 PM2.5，大端无符号整数 |

## 连接与诊断

登录报文发送后立即发送一次 `c2s_read`，与小程序抓包顺序一致，不等待 `login_res`。若 8 秒后仍没有状态，会补发一次不带 `names` 的读取；再等 8 秒仍无状态，才尝试订阅后读取。

连接保持采用三层保活：WebSocket 协议级 ping 每 10 秒一次、10 秒无 pong 判定超时；连接期间每 5 秒自动发送一次 `c2s_read`，避免设备因长时间没有 App 访问而休眠；应用层 `{"cmd":"ping"}` 每 30 秒一次。掉线后按 3 秒间隔自动重连。

“云端连接”实体提供以下属性：

| 属性 | 用途 |
| --- | --- |
| `last_stage` | 当前连接、读取或状态接收阶段 |
| `last_message_cmd` | 最近收到的云端消息类型，不包含消息内容 |
| `subscription_status` | 设备订阅是否被云端确认 |
| `raw_frames_received` | 已收到的原始帧数量 |
| `refresh_reads_sent` | 连接建立后已自动发送的保活读取次数 |
| `connection_attempts` / `login_responses` | 已尝试连接次数和已收到登录响应次数 |
| `last_login_result` | 最近一次登录结果：等待、成功或失败 |
| `last_raw_length` / `last_raw_error` | 最近原始帧长度和解析错误 |
| `last_close_code` / `last_close_reason` | 云端最近一次关闭连接的代码和原因 |
| `received_status` / `last_error` | 是否已有可用数据及最近错误 |

## 排查

在 `/config/configuration.yaml` 中临时加入：

```yaml
logger:
  logs:
    custom_components.airspa_ai_climate: debug
```

重启后查看“设置 → 系统 → 日志”。反馈时请删除 DID 等设备信息。

- `login_res.success=false`：检查 AppID、DID 和 WebSocket 地址。
- 能登录但 `raw_frames_received=0`：确认地址是 `wss://aisp.airspa.cn:81/完整DID`，不是 `/ws/app/v1`。
- 一直重连：确认 WebSocket 主机、81 端口及 `wss` 与抓包一致；`refresh_reads_sent` 持续增加说明保活读取正常发送，若仍掉线请记录 `last_error`、`last_close_code`、`last_close_reason`，以及 `connection_attempts`、`login_responses`、`last_login_result`。
- 原始帧长度不是 42 字节：集成会忽略该帧，需要补充新样本。
- 控制后状态不变：查看云端连接及新状态帧，不要连续重复点击。
